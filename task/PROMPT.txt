跨机构网络运营方需要将链路遥测统计转送给多个值班组。每个报表单独看都很粗，但两个组交换已经收到的报表后，可能把某个受保护站点的计数推成唯一值。请为本地仿真环境实现转送前审计、报表选择及原子发布账本。所有站点、值班组、可用转送网关和计数都是虚构的，输入来自本地文件，无需连接设备或真实服务。

一期遥测包含有界非负整数计数单元。输入给各单元上下界、可公开的等式，以及若干受保护的线性总值和最低可能值个数 k。每张候选报表给整数系数、拟发布的精确值、收件组、可能的转送网关、发布效用和可覆盖的值班需求。审查者只能使用上下界、公开等式与该观察者确实收到的报表等式。允许的观察者为单组及输入列出的双组联盟；联盟合并双方的历史发布记录，重复报表只提供一条等式。送达过的报表无法撤回其知识，关闭网关或删去当前的一张报表不会抹掉旧信息。不同期的计数单元可经公开等式关联，旧发布不能只因换期而丢弃。

audit 对给定送达记录逐批审查每个观察者，不把同一批的部分送达当成一个额外时刻。对每个受保护总值报告能否达到 k 个不同的整数取值。上下界跨度不能代替可取值数量。如果达标，给 k 个升序最小取值及各自字典序最小的可重放计数赋值；若不足，给全部可取值及对应见证，指出最早触发违规的一批和相关观察者。若观察者的等式本身无解，报告证据冲突，给按约束条数最少、再按约束 ID 字典序决胜的不可满足子集；不能将矛盾当成保护成立。报表值与本期由输入提供的真实合成计数不符时不得发布；真实计数不用于缩小观察者可推知的范围。

plan 选一组固定报表，在无故障及每个登记的单网关失效情景下都满足值班需求和保护下限。报表只要有一个可用网关，就会送给它指定的全部收件组；报表彼此同时入账，多网关转送不得重复计效用。值班需求给必须收到报表的组及可代替的报表集合，各情景允许通过不同报表满足。只对该情景实际送达的报表计算新等式，再和既有发布合并。按无故障时的发布效用之和最大、未发布报表数最少、排序后的已发布报表 ID 序列字典序依次择优。输出能复放的各情景送达集合、值班覆盖和隐私见证。若无解，给出按字典序最先的、使约束不可满足的最小值班需求子集，或者明确说明历史发布本身已违规。上限为 22 张候选报表、36 个计数单元、10 个观察者和 5 个网关；计数上界至多 12。复用等价证据状态或给出安全剪枝的理由，不展开全部计数赋值的笛卡尔积。

apply 用 SQLite 原子记录一期的报表、实际送达回执及计划所绑定的发布账本版本、联盟配置代次、公开等式版本和情景。应用时重算相符情景的覆盖及观察者证据；并发新发布或配置变更与版本不符时拒绝，失败不落部分报表。相同请求重放返回同一回执，冲突内容拒绝。小规模穷举要能对拍可取值、冲突子集和最优报表集。断言至少覆盖：单组安全但联合后只剩一个取值、可取值有缺口、旧报表跨期与新等式组合、真值不应泄漏到观察者约束、单网关失效导致只能依赖另一张报表、局部高效用不等于全局最优、并发发布让旧计划失效、成功入账后丢回执再重放。

从空仓库提供可复跑的实现，使用 Windows 原生 Python 3.12、标准库和 CPU。调用形式是 python -m solution <命令> CASE.json，需要持久状态时指定 --db DB.sqlite。stdout 输出确定的 UTF-8 JSON，结构错误标出字段位置和错误码。README 写全输入输出及复现步骤，附本地样例和可由 python -m unittest discover -s tests -v 执行的断言。
